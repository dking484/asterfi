# AsterFi

A phone system built on Asterisk 22, with a web console in the style of UniFi Talk. It covers users and extensions, ring groups and queues, visual call flows (IVR), voicemail with email alerts, call history and recording, UniFi Talk phone adoption and provisioning, a browser phone, webhooks and a REST API.

## Install

Start with a fresh **Debian 12+** or **Ubuntu 22.04+** server (x86-64 or arm64, 2 GB RAM or more). Give it a static IP address on your phone network.

```bash
git clone https://github.com/dking484/asterfi.git
cd asterfi
sudo ./install.sh
```

The installer sets up everything AsterFi needs:

| Component | Source |
|---|---|
| Asterisk 22 and its English sounds and hold music | The distribution's package when it is version 22 or newer (as on Ubuntu 26.04). Otherwise it's built from source, which takes 10–30 minutes. |
| PostgreSQL | The distribution's package |
| Node.js 22 | The distribution's package if it is version 20 or newer, otherwise NodeSource |
| nginx with a self-signed HTTPS certificate | The distribution's package |
| ffmpeg, sox, lame, flite | The distribution's packages, used for audio conversion and the basic text-to-speech voice |
| Kokoro text-to-speech voices | Python venv in `/opt/asterfi/tts`, about 350 MB |
| AsterFi service and the nightly backup timer | This repository |

When it finishes, open `https://<server-ip>/` and create the first administrator. Then:

- **Settings > General**: set the web address, the public IP (if the server is behind NAT) and the time zone.
- **Settings > Email**: set the SMTP server for voicemail and missed-call emails.
- **Trunks & Routes**: add your SIP provider.

### Options

```bash
sudo SKIP_KOKORO=1 ./install.sh                             # skip the Kokoro voices (typed prompts use Flite)
sudo ASTERISK_FROM_SOURCE=1 ./install.sh                    # build Asterisk even if a package exists
sudo ASTERFI_TLS_NAMES=pbx.example.com ./install.sh         # extra names on the self-signed certificate
```

### Updating

```bash
git pull
sudo ./install.sh
```

Re-running the installer updates AsterFi in place. It keeps the database, settings, prompts, voicemail and certificate.

### Ports

| Port | Used for |
|---|---|
| 80, 443/tcp | Web console. Phones fetch the phonebook over port 80. |
| 5060/udp+tcp | SIP |
| 10000–20000/udp | Call audio (RTP) |
| 8080/tcp, 10001/udp | UniFi phone adoption (inform) and discovery |

If `ufw` is active, the installer opens these ports.

## Where things live

| Path | What |
|---|---|
| `/opt/asterfi` | Application: `server/`, `web/dist`, `tts/` |
| `/etc/asterfi/asterfi.env` | Database and Asterisk Manager credentials (generated) |
| `/etc/asterfi/tls/` | HTTPS certificate. Replace `asterfi.crt` and `asterfi.key`, then run `systemctl reload nginx`. |
| `/etc/asterisk/asterfi/` | Asterisk configuration generated by AsterFi (don't edit it by hand) |
| `/var/backups/asterfi` | Nightly backups (the last 14 are kept) |
| `/var/log/asterfi-install.log` | Log of the last install run |

Services: `asterfi`, `asterisk`, `postgresql`, `nginx`, `asterfi-backup.timer`. App logs: `journalctl -u asterfi`.

## Development

- `server/`: Fastify API, Asterisk config generator, AMI call tracker, UniFi listener.
- `web/`: React + Vite console. Use `npm run dev` for development and `npm run build` to produce `web/dist`.
- `deploy/deploy.sh`: pushes `server/src` and a built `web/dist` to an existing server over SSH. It reads the server address and password from `deploy/local.env`; copy `deploy/local.env.example` to create it.
- `docs/integration-guide.md`: REST API and webhooks.
